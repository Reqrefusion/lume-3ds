LUME 3DS - READY GAME PACKAGE

Recommended: use Lume3DS-SDCard.zip to install directly on a Nintendo 3DS.
This optional Windows package opens the same ready game on your PC.

1. Extract this ZIP into a new folder.
2. Run Install.cmd and select your own supported original Lume.exe.
3. Copy the generated sdmc/3ds folder to the SD card root.
4. Start Lume from Homebrew Launcher.

The 3D images, videos and audio are already prepared.
No 3D conversion, model downloads or compiler are required.
Your EXE is read locally; it is never executed or uploaded.
The developer folder is optional and is not needed on the SD card.
Existing output folders are never overwritten.
Allow at least 600 MiB free space on the PC before installation.
